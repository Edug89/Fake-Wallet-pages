# Fake Wallet — soporte y privacidad

Sitio estático público asociado a Fake Wallet. Este repositorio contiene únicamente las páginas públicas; no contiene el código de la app.

- Soporte: https://edug89.github.io/Fake-Wallet-pages/
- Privacidad: https://edug89.github.io/Fake-Wallet-pages/privacidad/
- Contacto público: edugproduce@gmail.com

## Publicación

GitHub Pages sirve la raíz `/` de la rama `codex/support-privacy-pages`. `.nojekyll` mantiene la publicación estática. No hay dependencias, scripts de seguimiento ni formularios.

## Mantenimiento

Edita `index.html` para soporte y `style.css` para los estilos. La política HTML se genera a partir de la política vigente de la app y se conserva también en `privacidad/politica.md`. Mantén ambas versiones web y la política incluida en la app sincronizadas. No incluyas credenciales ni archivos de configuración de Firebase en este repositorio.
